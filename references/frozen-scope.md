# 能力范围与版本证据

当前版本：1.1.0 私人开发版。0.3.0-demo 是早期合成样板基线，1.0.0 完成真实转换入口，1.1.0 新增回答末尾的网页来源清单。

## 已实现

- DeepSeek v3 普通导出的结构探查、特征覆盖抽样、任意 ID 选择、demo 和经确认后的 full 入口。
- 审核绑定源数据、品牌配置、时区和转换规则；全量需要 reviewed-demo 与已有用户批准声明。
- 问答、历史分支、片段、状态、附件、复杂 Markdown 和原始数据归档；独立落盘核验。
- 空标题、空检索、不完整编码、相对链接示例和未引用源文件处理。
- 来源品牌配置、规范化契约与未知来源的结构研究/适配流程。
- Obsidian CLI / Electron 原生核验，不使用桌面自动化。

## 边界

只做 AI 聊天导出到 Obsidian 笔记库的转换。不包含 NAS/云盘部署、挂载、同步、增量合并、自动摘要、知识提炼、事实核查、代码执行或缺失附件恢复。

DeepSeek v3 有原生适配；其他来源需检查实际格式并开发适配器。品牌配置和规范化契约不等于已支持每个平台的原生导出。复杂混合 HTML、非标准公式、新片段仍需样板验证；未知结构不静默丢弃。

## 证据与发布

verification-results.json 记录实际测试和视觉检查。frozen-files.json 是当前版本校验清单，随有依据的版本变更更新，不代替行为测试，也不是永久禁止开发。

所有 runnable fixtures、演示笔记及原始 JSON 均为合成数据。README 两张真实截图为用户授权的有限例外，见 visual-assets.md。仓库保持 private，许可证待选，不在本任务中公开开源。
